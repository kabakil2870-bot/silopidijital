SILOPI DIJITAL — VERCEL DEPLOYMENT

Project root: repository root (./). The files package.json, index.html, and src/main.tsx must be siblings under this root.

Vercel settings:
- Framework Preset: Vite
- Root Directory: ./
- Install Command: npm ci (or npm install)
- Build Command: npm run build
- Output Directory: dist

vercel.json rewrites SPA paths to /index.html so paths such as /admin can load directly. Supabase client settings are configured for the Silopi Dijital project in the app; the public publishable key is not a service secret. Never add service_role or sb_secret values to frontend environment variables.
